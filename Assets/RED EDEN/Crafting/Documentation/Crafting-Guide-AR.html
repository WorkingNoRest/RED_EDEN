ابدأ من هنا

كيف يعمل النظام؟

نظام RED EDEN يضيف التصنيع وجمع الموارد فوق Inventory System الموجود؛ لا ينشئ مخزونًا بديلًا. الموارد والمنتجات كلها عناصر Item مسجلة في قاعدة المخزون الحالية.

01 / الإعداد

تجهيز المشروع في Unity

  1. افتح المشروع وانتظر انتهاء تجميع السكربتات. يجب أن تظهر قائمة Tools > RED EDEN > Crafting في محرر Unity.
  2. شغّل Tools > RED EDEN > Crafting > Create Starter Data. ينشئ البيانات الناقصة ويجهز مراجع قاعدة البيانات وملفات موارد البداية. إذا كانت الأصول موجودة، لا يعيد إنشاء ملفات الموارد والوصفات الموجودة.
  3. اختر InventoryManager الموجود في المشهد، وأضف RED EDEN Item Database.asset إلى قاعدة البيانات التابعة/الإضافية في إعداداته. احتفظ بقاعدة المخزون الأصلية.
  4. تأكد من وجود اللاعب الذي يستخدم إعداد Player Tag في إعدادات المخزون، ووجود نافذة ItemContainer اسمها Inventory.
  5. أضف RED EDEN Crafting Database.asset إلى كل محطة. إعداد المحطة الافتراضي Station Type = Fabricator، ويجب أن يطابق وصفاتك.
  6. أضف Collider إلى جسم الطابعة واضبط نطاق الاستخدام وفق إعداد Use Distance. تفاعل اللاعب بالمحطات وعقد الموارد مضبوط على E.
  7. ضع عقد الموارد من ملفات Prefab الجاهزة أو أضف MartianResourceNode إلى كائن المورد، ثم اربط تعريف المورد.

02 / إعداد المحطة

إعداد محطة طباعة موثوقة

  1. أنشئ كائنًا للطابعة مع Collider مناسب لنطاق التفاعل، وأضف RedEdenCraftingStation.
  2. عيّن Database إلى قاعدة بيانات RED EDEN، واختر Station Type المطلوب.
  3. اترك Inventory Window = Inventory ما لم تكن نافذة المشروع تحمل اسمًا آخر.
  4. تأكد أن Operational مفعّل وأن وصفة المنتج تحمل نوع محطة مطابقًا.
  5. احفظ المشهد، ثم افحص معرف المحطة. يُنشأ معرف ثابت للمكوّن عند التحرير.

معرف ثابت لكل محطة

المعرف يربط بيانات الحفظ بالطابعة نفسها. عند تكرار محطة في المشهد، حدّد النسخة الجديدة، ثم من قائمة المكوّن اختر Generate New Stable Station ID. لا تترك نسختين بمعرف واحد: الحفظ قد يرفضه كي لا يكتب حالة محطة فوق أخرى.

قاعدة عملية: محطة واحدة = معرف واحد + قاعدة بيانات صالحة + نافذة مخزون صحيحة + Collider قابل للوصول.

حالات المحطة

03 / تجربة اللعب

من الاقتراب حتى تسلّم المنتج

  1. اقترب من محطة أو عقدة ضمن نطاق استخدامها، ثم اضغط E. عند المحطة تظهر واجهة خاصة بها.
  2. راجع قائمة الوصفات. تظهر الوصفات المسجلة لنوع المحطة؛ الوصفة غير المتاحة بسبب غياب مواد أو مشكلة مخزون تكون باهتة وغير قابلة للاختيار.
  3. اختر وصفة متاحة. تعرض التفاصيل اسم المنتج، الكمية المطلوبة والمتاحة لكل مورد، ناتج الطباعة، والوقت.
  4. اضغط START PRINT. تُفحص الوصفة والمخزون ثم تُخصم المواد مرة واحدة عند بدء المهمة. الضغط المتكرر لا يطلق وظيفة ثانية لأن المحطة تصبح مشغولة.
  5. تابع حالة PRINTING ونسبة التقدم والوقت المتبقي. يمكنك إغلاق الواجهة؛ الإغلاق لا يلغي المهمة.
  6. بعد اكتمال الطباعة تظهر حالة OUTPUT READY. إذا كانت الواجهة مفتوحة استخدم COLLECT OUTPUT أو اضغط E.
  7. إذا كانت الواجهة مغلقة، الضغط الأول على E يفتحها عند وجود الناتج؛ اجمعه بزر COLLECT OUTPUT أو اضغط E مرة أخرى.
المخزون ممتلئ؟ تظهر رسالة فشل التسليم، لكن الناتج يظل في الطابعة. أفرغ مساحة ثم أعد محاولة الجمع.
كرر E؟ لا يؤدي الضغط المتكرر إلى مضاعفة الناتج. بعد نجاح التسليم تُزال نسخة الناتج المعلقة من المحطة، فلا توجد نسخة ثانية للجمع.

ما الذي تعرضه واجهة التصنيع؟

  • عنوان الواجهة: RED EDEN / FABRICATOR.
  • حالة الطباعة أو حالة الاستعداد أو رسالة اكتمال التصنيع.
  • تفاصيل الوصفة: المواد المتوفرة/المطلوبة، المنتج والكمية، ومدة التصنيع.
  • الأزرار: START PRINT وCOLLECT OUTPUT وCLOSE.

05 / توسيع قاعدة التصنيع

إضافة مورد أو وصفة جديدة

إضافة عنصر مخزون ومورد

  1. أنشئ عنصر Item في قاعدة عناصر المشروع، وحدد الاسم وخصائص التكديس.
  2. من القائمة Assets > Create > RED EDEN > Crafting > Resource Definition أنشئ تعريفًا، ثم عيّن ID فريدًا واسم العرض والوصف والنوع وعنصر المخزون.
  3. اضبط بيانات المورد الاختيارية: Purity وContamination والكثافة والمقاومة الحرارية وقوة المادة وطريقة الاستخراج وHarvest Amount.
  4. أضف تعريف المورد إلى مصفوفة Resources في قاعدة RED EDEN Crafting Database، وعنصره إلى قاعدة المخزون التابعة في InventoryManager.
  5. أنشئ عقدة/Prefab للمورد واربط تعريف المورد. شغّل إنشاء بيانات البداية إذا كنت تريد إنشاء/إصلاح Prefab المورد الافتراضي باسمه.

إنشاء وصفة

  1. أنشئ أصل RED EDEN > Crafting > Recipe.
  2. حدد معرّفًا ثابتًا وفريدًا، اسم العرض والوصف، نوع المحطة، ومدة أكبر من صفر.
  3. أضف مكونًا واحدًا أو أكثر؛ لكل مكوّن اختر موردًا مسجلًا في قاعدة المحطة وحدد كمية موجبة.
  4. اختر Output Item مسجلًا في قاعدة المخزون، ثم حدد Output Amount موجبًا.
  5. أضف الوصفة إلى مصفوفة Recipes في قاعدة التصنيع. احفظ الأصول ثم شغّل التحقق.

06 / جمع الموارد

إعداد عقدة مورد قابلة للحصاد

المكوّن MartianResourceNode يرث من Trigger الموجود في Inventory System. يضيف المورد إلى المخزون أولًا، ثم يخفض كمية العقدة؛ إذا تعذر إدخال الكمية بسبب امتلاء المخزون، لا تُستنزف العقدة.

خطوات العالم والـPrefabs

  • للبداية استخدم ملفًا داخل Assets/RED EDEN/Crafting/Data/Prefabs/ResourceNodes.
  • اسحب الـPrefab إلى المشهد، اضبط حجمه ومظهره وCollider ونطاق التفاعل، واترك المكوّن مرتبطًا بتعريف المورد الصحيح.
  • كل عقدة في العالم تحتاج Stable Node ID مستقلًا. بعد نسخ العقدة، استخدم Generate New Stable Node ID من قائمة المكوّن على النسخة.
  • عند نفاد الكمية، تُعطّل المرئيات والـColliders الخاصة بالعقدة، ولا يُعطّل جذرها أو يختفي المكوّن المسؤول عن الحفظ.
إعادة الظهور: العداد يتقدم باستخدام وقت اللعب Time.deltaTime. لا تُحتسب ساعات غياب اللاعب عن اللعبة؛ لا يوجد عداد زمني خارج اللعبة في التنفيذ الحالي.
07 / الحفظ والاستعادة

ما الذي يُحفظ، وكيف تعيد الاختبار؟

بيانات RED EDEN تُسجّل في JSON حفظ المشهد ضمن مسار الحفظ الموجود في InventoryManager. لا يوجد نظام حفظ مستقل للمخزون أو للكرافتينج.

حالة الطابعة
معرّف المحطة، حالة التشغيل، ID الوصفة، الزمن المتبقي والمدة والتقدم، ID الناتج وكميته، وحالة جمعه.
حالة عقدة المورد
معرّف العقدة والمورد، الكمية المتبقية، الاستنزاف، إعداد إعادة الظهور والوقت المتبقي.
  1. تأكد من تفعيل إعدادات حفظ المخزون الحالية واستخدم إجراء الحفظ المعتاد للمشروع.
  2. احفظ أثناء مهمة نشطة للتحقق من تسجيل ID الوصفة والوقت المتبقي. مواد الوصفة سبق خصمها؛ الاستعادة لا تخصمها مرة ثانية.
  3. احفظ بعد اكتمال الطباعة وقبل الجمع للتحقق من بقاء الناتج المعلّق في محطته.
  4. استعد الحفظ عبر نظام المشروع المعتاد، مع وجود المحطات والعقد ذات المعرفات نفسها في المشهد وقواعد التعريفات متاحة.
  5. قارن كميات المخزون بحفظ Inventory System، وتأكد أن حفظ الطابعة لم يضف نسخة أخرى لعناصر المخزون.

شروط وحدود مهمة

  • الحفظ يحتاج معرفات فريدة لكل محطة وعقدة. المعرف المكرر أو المفقود يؤدي إلى تحذير/رفض حفظ بيانات المشهد لمنع الكتابة فوق حالة أخرى.
  • الوصفة والمنتج والمورد يستعادون عبر IDs من قاعدة البيانات، لا عبر حفظ مرجع Unity وحده. عند غياب تعريف محفوظ، يسجل النظام تحذيرًا ويحتفظ بمعلومات ID القابلة للاسترداد.
  • مخزون اللاعب محفوظ في مساره الأصلي فقط. لا تعِد إنشاء عنصر في المخزون بسبب وجود ناتج محفوظ بالمحطة؛ الناتج محطة وليس عنصرًا مملوكًا بعد.
  • تعطل تسلسل بيانات المشهد يوقف تحديث الحفظ بدل استبدال البيانات السابقة بنجاح زائف.
  • نسخة بيانات المكوّن الحالية هي Schema Version 1؛ ترقية الصيغة مستقبلًا تتطلب دعم قراءة الإصدارات السابقة.
08 / الشكل والحركة

إعداد مؤثرات الطابعة الإجرائية

أضف RedEdenPrinterVisuals إلى جذر الطابعة. إذا لم تُسند أنظمة الجسيمات أو ضوء التصنيع، ينشئ المكوّن مؤثرات بسيطة وقت التشغيل دون أصول مدفوعة.

المجموعةما الذي تربطه؟السلوك

توصيلات آمنة

  • استخدم كائنات فرعية مرئية كـMoving Parts وExpanding Parts؛ لا تسند جذر المحطة.
  • لا تسند أي Transform يحتوي Collider. المكوّن يتجاوز تحريكه ويصدر تحذيرًا إذا كان Collider موجودًا تحته.
  • ضع المؤثرات والجسيمات على أبناء منفصلين عند منطقة الطباعة، مع ضبط مواقعها محليًا لتناسب نموذجك.
  • اختبر الألوان والخامات والإضاءة في URP وإعدادات المنصة المستهدفة، واضبط المنحنيات والسرعة من Inspector.
المؤثرات تشمل الغبار اللامع والنجوم والجسيمات الدوامة، ظهور شكل المنتج تدريجيًا، حركة أجزاء الماكينة، انبعاثًا/إضاءة متحركة، وانفجارًا ضوئيًا مميزًا عند اكتمال الطباعة.

اختبار يدوي مقترح قبل النشر

  1. اجمع موردًا، ثم ابدأ وصفة بكمية صحيحة وتأكد من الخصم مرة واحدة.
  2. جرب وصفة بلا خام كافٍ، ومخزونًا ممتلئًا، والنقر المتكرر على زر التصنيع.
  3. أغلق واجهة محطة أثناء العمل وافتح محطة ثانية؛ تحقق من استقلال التقدم.
  4. اجعل المخزون ممتلئًا عند الجمع، ثم أفرغ خانة وأعد الجمع؛ تحقق من عدم فقد أو تكرار الناتج.
  5. احفظ أثناء تصنيع، وبعد الجاهزية، وبعد استنزاف عقدة؛ استعد الحفظ وافحص الأعداد والمعرفات.

تغير شكل الطابعة أو تصادمها أثناء الحركةتم ربط الجذر أو Transform يحوي Collider إلى قائمة التحريك.أزل ذلك الربط واستخدم Mesh فرعيًا بلا Collider.
